# trading-journal

- `index.html`: **Tradalytics**, the trading journal (open it in a browser, or visit the GitHub Pages site).
- [`daytrade-arena/`](daytrade-arena/): **Day Trade Arena**, a multiplayer day-trading game with room codes, bots, four modes, a live order book and full charting. Exports fills and candles back into Tradalytics.
- [`study-town/`](study-town/): **Study Town**, a town-building revision game.
